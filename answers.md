## 1. What is inside the request object (`req`)?

<!-- write your answer here -->
The req object contains information about the HTTP request.

## 2. What is inside the response object (`res`)?

<!-- write your answer here -->
The res object is used to send a response back to the client.

## 3. What does `app.use()` do?

<!-- write your answer here -->
app.use() adds middleware to the Express application.

Middleware runs during request processing.
